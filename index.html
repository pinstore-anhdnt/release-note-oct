Recommendation: titles should update to iOS 3.20.0 / Android 3.20.0 to pick up the fix for the Decree 13 form on iOS 27 and the crash fix for lost decryption keys on Android.
BUG FIXED

Decree 13 form not shown after account recovery (iOS 27)

On iOS 27 devices, in titles using the Direct Login - Recovery Account flow, the Decree 13 form closed right after appearing once the player had successfully recovered a valid account. From iOS 3.20.0 the form displays correctly after recovery and the SDK returns the login result to the game.

⚠️ For titles using Direct Login - Recovery Account on iOS, before the next release. Update the SDK to iOS 3.20.0 or higher.

CHANGED

Guest login no longer crashes when the decryption key is lost (Android)

On Android, when the app lost the key used to decrypt login data stored on the device, SDK versions from 3.17.0 up to before 3.20.0 could crash the app on entering the game. From Android 3.20.0 the SDK no longer crashes: unreadable data is cleared and the player continues to log in.

🎧 CS PlatformPIC: GiangPMH · 9 updates Read full 
FEATURE

Self-service setup and management of Zalo OA accounts on CS Platform

CS Admins can now link and manage a product’s Zalo OA directly in the Zalo OA tab of Product Detail: view the list, link via Zalo authorization, view details, and delete one or several connections.

⚠️ CS Admins need to re-link the OAs they want to use on the new screen. Do not change the Zalo app key after OAs have been linked, otherwise the OAs will stop renewing automatically until they are linked again.

FEATURE

New "Solve" status and automatic ticket closing over time

Tickets now have a Solve status. Handling groups can configure an auto-close time: if a ticket is in Solve, has no assignee and the customer sends no further messages, it automatically moves to Resolved when the time runs out.

⚠️ CS Leaders should review and adjust the auto-close time for each handling group.

🏆 VNGGames ClubPIC: LocLV2 · 17 updates Read full 
CHANGED

Group general codes now span multiple markets of one game (Giftcode)

Group general codes no longer apply to VN only: a group can hold codes from multiple markets at once but belongs to a single game (games can’t be mixed in one group). The redemption limit now combines redemptions across all markets in the group, applying to both existing and new groups. The screen is renamed "Group General Code"; group deletion is removed, leaving only enable/disable.

CHANGED

Code Hub toggle and scheduled display time (Reward Tool)

The Edit Active Code page on the Reward Tool now has a per-game Code Hub on/off option (default off; once a game is on Code Hub, turn it on to show the Code Hub section on that game’s Giftcode page), editable by anyone with access to the Active Code page.

🎁 PromotionPIC: ChiNB · 3 updates Read full 
CHANGED EFFECTIVE 15/10/2026

Dual approval by PM Game & Tool Owner for all events

Effective 15/10/2026, all events must go through a two-level approval process on VNGGames Hub (PM Game → Tool Owner) before release. The Promotion system automatically creates a ticket on VNGGames Hub, assigns it to the corresponding approvers, and syncs the "Waiting for approval" status to the Admin Tool.

⚠️ GS must submit approval requests at least 3 days before the Air date to give QC sufficient time for testing and to ensure release quality. Once the event is ready on Production, GS should proactively notify the Tool Owner to coordinate approval.

CHANGED EFFECTIVE 01/10/2026

Enhanced security for Promotion Admin Tool access

To strengthen security, prevent attacks and control system access, the Promotion Admin Tool is now accessible only from the VNG Corp internal network or via GVPN, restricting unauthorized access from external networks. Working at the office: Use the VNG Corp internal network as usual. Working remotely: Connect to GVPN before accessing the Admin Tool.

⚠️ Users accessing the Admin Tool from outside the VNG Corp network need a GVPN account and must connect before use. Search for Connecting to GVPN on [Your OS].

🚀 Launcher Level UpPIC: TienBT · 4 updates Read full 
FEATURE

Community: a community for every game in the launcher

The launcher has a new Community tab. Players choose an in-game screenshot, add a caption (suggested captions are available) and post it. Every post is moderated before it goes public. Community is live for all games in every market.

FEATURE

Webshop widget when launching a game from its shortcut

When a player launches a game from its desktop shortcut, or presses Play in the launcher, a small widget appears in the corner of the screen while the game starts. It shows artwork, a short message and a "Top up" (Nạp game) button that opens that game’s Webshop. Enabled for all games.

🔐 VNGGames AccountPIC: AnhHTH2 · 4 updates Read full 
CHANGED

SSO extended to Sign in with Apple (SIWA) across all stores

SIWA data has been fully migrated from VNG Sing to VNGGames Sing, and the data of these two stores has been synced to the VNGGames VN store. Allows 100% of games to use SSO login across all 4 stores: VNG Group, VNGGames Vietnam, VNG Sing and VNGGames Sing.

⚠️ Internal GPP service teams need to update their SSO integration to fully cover all 4 stores.

FEATURE

Zing ID username recovery

Zing ID is moving toward no longer storing PII (personally identifiable information) and supporting only username + password login. As a result, the other ways users sign in to Zing ID (email, phone number, Facebook, Google) will soon be discontinued. For users who usually sign in to Zing ID with email, phone number, Facebook or Google, this brand-new feature lets them recover their Zing ID username themselves via the "Can’t log in?" CTA, without contacting CS.

⚠️ End users should be informed about the new feature and given guidance on how to use it.

💳 PAY · WebshopPIC: ThaoNDT2 · 2 updates Read full 
CHANGED

WSOT moves from Mytool to VNGGames Hub

Webshop Operation Tool (WSOT) helps Game Studios and the operations team manage their webshops on their own, and is now available on VNGGames Hub (Pay → Shops and Change Management). Games and GS teams will move from Mytool to Hub in planned waves. GS teams will be granted access on Hub when their wave comes. A single person cannot hold both the Approver and Executor roles on the same game.

FEATURE

Ghost Story: manual-input In-game bonus Voucher, 7 markets

A manual-input In-game bonus Voucher campaign for Ghost Story was released in VN, TH, SG, MY, PH, ID and OT. Setup: each market has 3 codes, and each code is a separate campaign. A user who uses code 1 can still use codes 2 and 3.
